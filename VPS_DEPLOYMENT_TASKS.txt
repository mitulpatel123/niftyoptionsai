NIFTYOPTIONSAI - GITHUB + HOSTINGER VPS DEPLOYMENT TASKS
=========================================================

Purpose
-------
Move the complete NIFTY/BANKNIFTY AI trading data system from the MacBook to a
Hostinger KVM VPS running Ubuntu, so market data collection, feature building,
labeling, and model training run automatically on the server.

Important Reality Check
-----------------------
The server can run the pipeline fully automatically with cron/systemd.

We have implemented an automated Dhan Access Token generation script 
(scripts/auto_token.py) which uses the official `dhanhq` library and `pyotp` 
to completely automate the token refresh. 

You no longer need to update the token manually. Simply provide your 
DHAN_PIN and DHAN_TOTP_SECRET in the `.env` file once!

The VPS agent must set up everything else:
- database
- code
- dependencies
- schema
- old data migration
- systemd service/timer
- backups
- verification

Fully Automated Process:
The system automatically generates a new token every morning when the 
daily pipeline starts. The generated token is automatically injected 
into memory and saved back to the `.env` file for other scripts to use.

STEP 1 - BASIC SERVER SETUP
---------------------------

Run as root or sudo user:

    sudo apt update
    sudo apt upgrade -y
    sudo apt install -y curl wget git vim unzip build-essential software-properties-common ca-certificates gnupg lsb-release
    sudo apt install -y python3 python3-venv python3-pip

Create app user:

    sudo adduser --disabled-password --gecos "" niftyai
    sudo usermod -aG sudo niftyai

Create project directory:

    sudo mkdir -p /opt/niftyoptionsai
    sudo chown -R niftyai:niftyai /opt/niftyoptionsai


STEP 2 - INSTALL POSTGRESQL + TIMESCALEDB
-----------------------------------------

Preferred approach: install PostgreSQL and TimescaleDB from official package
repositories.

On Ubuntu, package names vary depending on Ubuntu and PostgreSQL version.
Use PostgreSQL 16 or 17. PostgreSQL 16 is usually easier on Ubuntu VPS.

Install PostgreSQL:

    sudo apt install -y postgresql postgresql-contrib

Check version:

    psql --version
    pg_lsclusters

Install TimescaleDB following the official Timescale Linux instructions:

    https://docs.timescale.com/self-hosted/latest/install/installation-linux/

Common package examples:

    sudo apt install -y timescaledb-2-postgresql-16

or, if PostgreSQL 17 is installed and the package exists:

    sudo apt install -y timescaledb-2-postgresql-17

Tune TimescaleDB:

    sudo timescaledb-tune --quiet --yes
    sudo systemctl restart postgresql

Verify PostgreSQL is running:

    sudo systemctl status postgresql --no-pager

STEP 11 - CREATE DAILY SYSTEMD SERVICE
--------------------------------------

Create service:

    sudo nano /etc/systemd/system/niftyoptionsai-daily.service

Paste:

    [Unit]
    Description=Nifty Options AI Daily Pipeline
    After=network-online.target postgresql.service
    Wants=network-online.target

    [Service]
    Type=oneshot
    User=niftyai
    WorkingDirectory=/opt/niftyoptionsai
    EnvironmentFile=/opt/niftyoptionsai/.env
    ExecStart=/opt/niftyoptionsai/.venv/bin/python /opt/niftyoptionsai/jobs/run_daily_pipeline.py --symbols NIFTY BANKNIFTY --train-model --train-days 30
    TimeoutStartSec=28800
    StandardOutput=append:/opt/niftyoptionsai/logs/daily-pipeline.log
    StandardError=append:/opt/niftyoptionsai/logs/daily-pipeline.err.log

    [Install]
    WantedBy=multi-user.target

Create logs folder:

    sudo mkdir -p /opt/niftyoptionsai/logs
    sudo chown -R niftyai:niftyai /opt/niftyoptionsai/logs

Reload:

    sudo systemctl daemon-reload

STEP 15 - WEEKLY BACKUP FOR MACBOOK DOWNLOAD
--------------------------------------------

Create backup folder:

    sudo mkdir -p /opt/niftyoptionsai/backups
    sudo chown -R niftyai:niftyai /opt/niftyoptionsai/backups

Create script:

    sudo -u niftyai nano /opt/niftyoptionsai/scripts/backup_db.sh

Paste:

    #!/usr/bin/env bash
    set -euo pipefail
    cd /opt/niftyoptionsai
    set -a
    source /opt/niftyoptionsai/.env
    set +a
    TS="$(date +%Y%m%d_%H%M%S)"
    OUT="/opt/niftyoptionsai/backups/niftyoptionsai_${TS}.dump"
    PGPASSWORD="$NIFTYAI_DB_PASSWORD" pg_dump \
      -h "$NIFTYAI_DB_HOST" \
      -p "$NIFTYAI_DB_PORT" \
      -U "$NIFTYAI_DB_USER" \
      -d "$NIFTYAI_DB_NAME" \
      -Fc \
      -f "$OUT"
    gzip "$OUT"
    find /opt/niftyoptionsai/backups -type f -name "*.dump.gz" -mtime +30 -delete

Make executable:

    chmod +x /opt/niftyoptionsai/scripts/backup_db.sh

Add weekly cron:

    sudo -u niftyai crontab -e

Add:

    0 18 * * 6 /opt/niftyoptionsai/scripts/backup_db.sh >> /opt/niftyoptionsai/logs/backup.log 2>&1

Download backup to MacBook weekly:

    scp niftyai@YOUR_SERVER_IP:/opt/niftyoptionsai/backups/latest_or_filename.dump.gz ~/Downloads/

Or list backups:

    ssh niftyai@YOUR_SERVER_IP "ls -lh /opt/niftyoptionsai/backups"

STEP 18 - COMMON ERRORS
-----------------------

1. Dhan DH-901 Invalid Authentication
   Meaning: token expired or wrong token/client id.
   Fix: generate fresh token, update .env, restart service.

2. Dhan DH-904 Rate Limit
   Meaning: too many API calls.
   Current mitigation:
   - option chain is every few seconds
   - option OHLC is ATM-only by default
   - option OHLC interval is 300 seconds
   - websocket has backoff on 429

3. Websocket 429 / blocked
   Meaning: Dhan blocked websocket reconnect attempts from IP/client.
   Fix:
   - wait 30+ minutes
   - do not restart repeatedly
   - keep reconnect backoff enabled

4. Timescale extension missing
   Fix:
   - install correct timescaledb package for installed PostgreSQL version
   - run timescaledb-tune
   - restart PostgreSQL
   - run CREATE EXTENSION IF NOT EXISTS timescaledb;

5. Feature store empty after market close
   Check:
   - raw data exists
   - run build manually:
     python jobs/build_labels_daily.py --date YYYY-MM-DD --symbols NIFTY BANKNIFTY

6. Model not promoted
   This is normal if metrics are weak.
   Active model remains the prior better model.

FINAL DAILY OPERATION
---------------------

The system runs completely unattended!

Every morning at 09:05 IST, the `systemd` timer automatically starts.
It generates a new Dhan token using your stored PIN and TOTP Secret,
starts fetching live data, and after market close, it automatically
builds the feature store and evaluates/trains your ML models!

Historical data rule:

    The VPS starts completely fresh. As it collects data day by day,
    it will build its own historical dataset for training.
